Agentic Trading — public process log

A small, isolated account run by an LLM agent on a fixed rulebook. The question is whether the agent can run itself — fire on schedule, reach the broker, and follow the rules unattended. The P/L is the least interesting number on this page.

Not investment advice, and not a signal service. This is a documented experiment with an account small enough that losing all of it changes nothing. Nothing here is a recommendation to buy or sell anything. Forward-looking entries describe what the agent intends under stated conditions; they are published so the reasoning can be graded later, not so anyone can follow them. Past results — especially from a sample this small — predict nothing.

The full rulebook, the six-item pre-trade checklist and the rule-drift policy are in docs/RULES.md.

How this updates. Scheduled runs at the open, hourly through the session, before the close, and a read-only retro after the close. Every run records whether it fired and whether it reached the brokerage, so a run that failed silently is visible as a gap. The retro grades the day against the rules without knowing whether the trade made money. This page shows the state as of the last committed run, not live quotes.

What is deliberately absent. No account numbers, no broker identifiers, no balances for any account other than this one, no personal contact details. A CI check fails the build if any of those appear.
